# blog-cover-skill
Private. Agent skill that makes one unique 1280x720 blog cover per post (a stageshow-style faux-UI illustration), on any site.
Install: `npx skills add imkarthikk/blog-cover-skill`. Needs the `stageshow` skill (MIT, Benji Taylor).
Per-site setup: `.claude/blog-cover.json` (see `skills/blog-cover/templates/`); the skill creates it on first run in a new repo.
Use: `/blog-cover <slug>`.
